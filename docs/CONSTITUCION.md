# Constitución del proyecto DecorArte

1. **Marca coherente:** toda vista usa DecorArte, el eslogan oficial y los tokens de `IDENTIDAD-MARCA.md`.
2. **Arquitectura por capas:** componentes presentan; hooks coordinan consultas; servicios encapsulan Supabase; validaciones se reutilizan.
3. **Seguridad por defecto:** RLS activa, autorización del servidor, secretos fuera del cliente y sin registro público.
4. **Mobile-first y accesible:** mínimo 360 px, teclado, foco visible, etiquetas, textos alternativos y movimiento reducido.
5. **Calidad verificable:** cada funcionalidad tiene spec, tareas, tests y verificación; no se afirman pruebas no ejecutadas.
6. **Contenido honesto:** no se inventan precios, stock, testimonios, métricas ni confirmaciones comerciales.
7. **IA supervisada:** los agentes proponen y ejecutan cambios acotados; el estudiante revisa código, tests, seguridad y decisiones, y debe poder defenderlos.
8. **Simplicidad mantenible:** evitar dependencias y abstracciones innecesarias; documentar cualquier cambio de stack o esquema.
